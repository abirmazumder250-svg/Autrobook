# Security Policy

## Supported Versions

The following versions of Autrobook are currently supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| 0.9.x   | :x:                |
| < 0.9   | :x:                |

> Only the latest 1.0.x version receives security updates.

## Reporting a Vulnerability

If you discover a security vulnerability in Autrobook, please do NOT open a public issue.

**How to report:**
1.  Email: `autrobooksupport@gmail.com`
2.  Subject: `[Autrobook Security] Vulnerability Report`
3.  Include details: steps to reproduce, affected version, and impact

**What to expect:**
- Acknowledgement within 24-48 hours
- We will work to fix the issue within 7 days
- You will be credited in the README if you want

Thank you for helping keep Autrobook safe 💚
